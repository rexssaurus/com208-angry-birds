# Angry Birds Times · COM208

Una crónica web para la primera sesión de una clase de vibe coding: decisiones editoriales y creativas del equipo, implementación con IA y comprobación de datos.

[Ver la web](https://rexssaurus.github.io/com208-angry-birds/)

## Referencias para la clase

- [Base de 100 niveles (CSV)](datos/angry_birds_100_niveles_simulados.csv)
- [Descripción de variables y reglas](datos/ficha_datos.json)
- [Brandbook de Angry Birds (2011)](referencias/AngryBirds-2011.pdf)
- [Guía docente de 60 minutos](GUIA-DEMO.md)

Los datos siguen las reglas definidas por el docente: cuatro bajas por ave sin protección, tres con madera y dos con piedra. Las imágenes y el brandbook de Angry Birds pertenecen a sus respectivos titulares y se utilizan como referencia visual de esta clase. Este proyecto no es un sitio oficial de Angry Birds.

## Publicación

Sitio estático alojado en GitHub Pages desde la raíz de la rama `main`. No requiere compilación ni dependencias. Para actualizarlo, se modifican los archivos de esta carpeta y se suben los cambios a `main`.
